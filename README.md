# نظام متابعة البريد — مكتب النائب عدي عواد الحسين

## الملفات
- `index.html` — صفحة المواطنين (يفتحها رمز QR): تبويب البريد + تبويب نشاطات النائب
- `admin.html` — لوحة السكرتارية: تسجيل الكتب ومراحلها، نشر النشاطات، تحميل الفورمة مع QR
- `config.js` — الإعدادات (Firebase، أنواع الكتب ومددها، المراحل الجاهزة)
- `firestore.rules` — قواعد الحماية

## خطوات التشغيل
1. ارفع المجلد إلى مستودع GitHub `Maan` داخل مجلد اسمه `barid`
   → يصير الرابط: https://maanyaseen94-eng.github.io/Maan/barid/
   (رمز QR بالفورمة الجاهزة مربوط على هذا الرابط)
2. أنشئ مشروع Firebase وفعّل **Firestore** و **Authentication (Email/Password)**.
3. انسخ إعدادات الـ Web App إلى `config.js` بدل `null`.
4. من Authentication أضف حسابات موظفي السكرتارية، وضع إيميلاتهم في `firestore.rules` ثم انشر القواعد من Firestore > Rules.
5. افتح `.../barid/admin.html` وسجّل الدخول.

> قبل ربط Firebase يشتغل النظام بوضع تجريبي على نفس الجهاز فقط.

## طريقة العمل
- عند صدور كتاب: سجّله باسم المواطن الثلاثي ورقم هاتفه وموضوعه، والتاريخ المتوقع يُحسب تلقائياً حسب نوع الطلب.
- كل ما يتحرك الكتاب: أضف مرحلة (العنوان، مكان الكتاب، التاريخ). آخر مرحلة تظهر للمواطن كـ "المرحلة الحالية".
- المواطن يمسح QR ← يكتب اسمه الثلاثي أو رقم هاتفه ← يشوف كل كتبه: الموضوع، العدد، الجهة، مكانه الحالي، والتاريخ المتوقع.
- تگدر ترفع صورة الكتاب (حتى 3 صفحات) وتظهر للمواطن ضمن التفاصيل.
- لا يمكن لأحد تصفّح قائمة الكتب؛ تظهر النتائج فقط لمن يكتب الاسم أو الرقم المطابق.
